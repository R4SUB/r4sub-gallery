02

Unify Evidence from Multiple Sources

Standardize findings from Pinnacle 21, manual reviews, and other tools into one validated table.

Every submission relies on evidence from multiple tools and teams — Pinnacle 21 outputs, manual review findings, traceability checks. Without standardization, inconsistencies slip through. R4SUB normalizes all these inputs into a single, schema-validated evidence table with consistent severity labels and result codes, so nothing is lost in translation.

Show code & output

Code

library(r4subcore)

ctx <- r4sub_run_context(
  study_id = "CDISCPILOT01", environment = "PROD", user = "demo_user"
)

quality_findings <- data.frame(
  indicator_id = c("QUAL_P21_ERROR", "QUAL_P21_ERROR", "QUAL_P21_WARN"),
  asset_id     = c("ADSL", "ADAE", "ADLB"),
  source_name  = c("pinnacle21", "pinnacle21", "pinnacle21"),
  result       = c("fail", "pass", "warn"),
  severity     = c("high", "info", "medium"),
  ...
)
ev_quality <- as_evidence(quality_findings, ctx = ctx)

## Canonicalize inconsistent labels
canon_severity(c("HIGH", "Low", "CRITICAL", "Info"))
# [1] "high" "low" "critical" "info"

Verify Data Lineage End-to-End

Ensure every analysis variable traces back to its source — before a reviewer asks.

Regulators expect every ADaM analysis variable to trace back to its SDTM source. Missing links trigger review queries and delays. This demo automatically maps 36 ADaM variables to their SDTM origins, flags 11 orphan variables with no source link, and quantifies coverage at 69% — giving teams a clear picture of traceability gaps to fix before filing.

Code

library(r4subtrace); library(r4subdata)

tm <- build_trace_model(

## Examine diagnostics

Identify and Prioritize Submission Risks

Know which risks matter most and where to focus remediation effort.

Not all issues are equal. A duplicate record in a safety dataset is far more critical than a label length warning. R4SUB uses FMEA methodology to score each risk by probability, impact, and detectability, producing a Risk Priority Number (RPN) that tells teams exactly where to focus. It can also auto-generate risks directly from existing evidence — turning 250 findings into 83 prioritized risks automatically.

Show code & output

Code

library(r4subrisk); library(r4subdata)

rr <- create_risk_register(risk_register_pharma)
rr <- compute_risk_scores(rr)

## Auto-generate risks from evidence
auto_risks <- evidence_to_risks(evidence_pharma)
auto_rr <- compute_risk_scores(auto_risks)

## Apply mitigations
rr_mitigated <- apply_mitigations(rr, ...)

05

Get a Single Readiness Score

Distill hundreds of findings into one number that answers “Are we ready?”

The Submission Confidence Index (SCI) condenses quality, traceability, risk, and usability signals into a single 0–100 score with a clear decision band: ready, minor gaps, conditional, or high risk. Every point is fully explainable — stakeholders can drill into exactly which indicators are dragging the score down and by how much, making remediation discussions evidence-based rather than opinion-based.

Show code & output

Code

library(r4subscore); library(r4subdata)

ind_scores   <- compute_indicator_scores(evidence_pharma)
pillar_scores <- compute_pillar_scores(evidence_pharma)
sci          <- compute_sci(pillar_scores)
explanation  <- sci_explain(evidence_pharma)

07

Full Pipeline: Data to Decision

The complete workflow — from raw metadata to a go/no-go submission gate.

This is what a data-driven submission gate looks like. In under 80 lines of code, R4SUB takes raw metadata, builds traceability models, scores risks, consolidates 297 evidence rows across 4 domains, computes an SCI of 44/100 against the FDA NDA profile, and delivers a clear verdict: “NOT READY — Significant work required.” No ambiguity, no guesswork, fully auditable.

Show code & output

Code

## 1. Context
ctx <- r4sub_run_context("CDISCPILOT01", "PROD")

## 2. Traceability
tm <- build_trace_model(adam_metadata, sdtm_metadata, trace_mapping)
ev_trace <- trace_model_to_evidence(tm, ctx)

## 3. Risk
rr <- create_risk_register(risk_register_pharma)
rr <- compute_risk_scores(rr)

## 4. Combine & Score
ev_all  <- bind_evidence(evidence_pharma, ev_trace)
profile <- submission_profile("FDA", "NDA")
sci_cfg <- profile_sci_config(profile)
ps      <- compute_pillar_scores(ev_all, config = sci_cfg)
sci     <- compute_sci(ps, config = sci_cfg)

08

Stress-Test Your Assumptions

What if we weighted quality more heavily? Would the decision change?

Before committing to a scoring configuration, stakeholders need to know if the conclusion is robust. This demo varies pillar weights across 5 scenarios and tests 5 different decision thresholds. The result: this study scores “high risk” regardless of how weights are configured — the conclusion is stable, not an artifact of a particular weighting choice. That's the kind of confidence decision-makers need.

Show code & output

Code

library(r4subscore); library(r4subdata)

## Vary pillar weights
weight_scenarios <- list(
  "Default (35/25/25/15)"       = c(quality=0.35, trace=0.25, risk=0.25, usability=0.15),
  "Quality-heavy (50/20/20/10)" = c(quality=0.50, trace=0.20, risk=0.20, usability=0.10),
  "Risk-heavy (20/20/50/10)"    = c(quality=0.20, trace=0.20, risk=0.50, usability=0.10),
  "Equal (25/25/25/25)"         = c(quality=0.25, trace=0.25, risk=0.25, usability=0.25)
)

## Automated sensitivity grid
quality_weights <- seq(0.15, 0.55, by = 0.10)
weight_grid <- data.frame(
  quality = quality_weights,
  trace   = (1 - quality_weights) / 3, ...
)
result <- sci_sensitivity_analysis(evidence_pharma, weight_grid)

Compare Readiness Across Regions

Filing globally? See how the same data scores against 6 different agencies side by side.

Global submissions mean meeting requirements from multiple authorities simultaneously. This demo scores identical evidence against FDA, EMA, PMDA, Health Canada, TGA, and MHRA in one run. The result reveals that FDA is the strictest (SCI: 44.4) and PMDA the most lenient (SCI: 45.0) — but the 0.6-point spread means this study fails everywhere. Teams get a single view of multi-regional readiness instead of managing it in silos.

Show code & output

Code

authorities <- list(
  list("FDA", "NDA"), list("EMA", "MAA"),
  list("PMDA", "NDA_JP"), list("Health_Canada", "NDS"),
  list("TGA", "registration"), list("MHRA", "MAA_UK")
)

for (auth in authorities) {
  profile <- submission_profile(auth[[1]], auth[[2]])
  cfg     <- profile_sci_config(profile)
  ps      <- compute_pillar_scores(evidence_pharma, config = cfg)
  sci     <- compute_sci(ps, config = cfg)
  # ...collect results
}
