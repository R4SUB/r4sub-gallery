The Ecosystem

8 Packages, One Mission

Every package handles a specific aspect of submission readiness, from evidence schema to regulatory scoring and interactive dashboards.

r4subcore

Core evidence schema, parsers, and scoring primitives. The foundation everything builds on.

Core

r4subdata

Demo datasets: evidence tables, ADaM/SDTM metadata, risk registers, and regulatory indicators.

Core

r4subtrace

ADaM-to-SDTM traceability analysis. Build trace models, detect orphans, compute coverage levels.

Analysis

r4subrisk

FMEA-based risk quantification. Risk registers, RPN scoring, mitigation tracking.

Analysis

r4subscore

Submission Confidence Index (SCI) scoring engine. Indicator scores, pillar aggregation, decision bands.

Analysis

r4subprofile

Regulatory submission profiles for FDA, EMA, PMDA, Health Canada, TGA, and MHRA.

Analysis

r4subui

Interactive Shiny dashboard for exploring evidence, scores, and submission readiness.

Output

r4sub

Meta-package. One install, one library call to load the entire ecosystem.

  study_id = "CDISCPILOT01", environment = "PROD", user = "demo_user"

07

End-to-End Workflow

Complete pipeline: metadata → traceability → risk → evidence → SCI → go/no-go decision.

all packages build_trace_model() compute_sci() validate_against_profile()
Show code & output

Code

## 1. Context
ctx <- r4sub_run_context("CDISCPILOT01", "PROD")

## 2. Traceability
tm <- build_trace_model(adam_metadata, sdtm_metadata, trace_mapping)
ev_trace <- trace_model_to_evidence(tm, ctx)

## 3. Risk
rr <- create_risk_register(risk_register_pharma)
rr <- compute_risk_scores(rr)

## 4. Combine & Score
ev_all  <- bind_evidence(evidence_pharma, ev_trace)
profile <- submission_profile("FDA", "NDA")
sci_cfg <- profile_sci_config(profile)
ps      <- compute_pillar_scores(ev_all, config = sci_cfg)
sci     <- compute_sci(ps, config = sci_cfg)

library(r4subscore); library(r4subdata)

## Vary pillar weights
weight_scenarios <- list(
  "Default (35/25/25/15)"       = c(quality=0.35, trace=0.25, risk=0.25, usability=0.15),
  "Quality-heavy (50/20/20/10)" = c(quality=0.50, trace=0.20, risk=0.20, usability=0.10),
  "Risk-heavy (20/20/50/10)"    = c(quality=0.20, trace=0.20, risk=0.50, usability=0.10),
  "Equal (25/25/25/25)"         = c(quality=0.25, trace=0.25, risk=0.25, usability=0.25)
)

## Automated sensitivity grid
quality_weights <- seq(0.15, 0.55, by = 0.10)
weight_grid <- data.frame(
  quality = quality_weights,
  trace   = (1 - quality_weights) / 3, ...
)
result <- sci_sensitivity_analysis(evidence_pharma, weight_grid)
